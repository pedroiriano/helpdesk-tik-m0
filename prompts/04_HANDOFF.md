# Siapkan perpindahan agent

Perbarui checkpoint dan backlog sesuai bukti. Buat handoff dari templates/HANDOFF.md berisi task, requirement, SHA aktual atau hashes, dirty state, file berubah, command dan hasil, proses yang masih berjalan, blocker, keputusan terbuka dan langkah berikut. Jangan menyembunyikan test gagal atau asumsi. Agent penerus harus dapat melanjutkan tanpa membaca seluruh chat dan tanpa menulis ulang implementasi yang sudah sah.
