# PANDUAN DAN TATA KELOLA AGEN AI (.agents/)

Folder `.agents/` adalah pusat instruksi, sistem aturan (*system prompts*), dan standar rekayasa terpadu untuk semua model kecerdasan buatan (*AI Assistants / Autonomous Coding Agents*) yang bekerja pada repositori ini:

1. **[GEMINI.md](file:///d:/Proyek/UI%20UX/Landing%20Page/modern/.agents/GEMINI.md)**: Panduan & aturan resmi untuk **Google Gemini** dan ekosistem Antigravity.
2. **[CLAUDE.md](file:///d:/Proyek/UI%20UX/Landing%20Page/modern/.agents/CLAUDE.md)**: Panduan & aturan resmi untuk **Anthropic Claude** (Claude Code / Desktop).
3. **[CHATGPT.md](file:///d:/Proyek/UI%20UX/Landing%20Page/modern/.agents/CHATGPT.md)**: Panduan & aturan resmi untuk **OpenAI ChatGPT / GPT-4o / o1**.
4. **[CURSORRULES.md](file:///d:/Proyek/UI%20UX/Landing%20Page/modern/.agents/CURSORRULES.md)**: Aturan sistem universal untuk agen IDE (Cursor, Windsurf, Copilot).

Seluruh agen AI yang membaca proyek ini diwajibkan mematuhi:
- **Zero Third-Party Dependencies** (Murni Web Platform: HTML5, Modern CSS, ES2024+ Vanilla JS).
- **Strict Mobile-First Upward Progression** (Default HP 320px, hanya menggunakan `@media (min-width)`).
- **Enterprise Security** (CSP L3, Zero `innerHTML`, `rel="noopener noreferrer"`, Honeypot).
- **Kebersihan Root Folder** (Tidak ada file aturan atau file sampah acak di root folder).
