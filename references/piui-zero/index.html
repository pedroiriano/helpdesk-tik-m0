Daftar Halaman & Kelompok Menu Aplikasi

Daftar halaman disusun ke dalam 4 kelompok menu yang mudah dipahami pengguna.

Rute sesuai manifest
Kelompok Menu Nama Halaman & Fungsi Indeks Mesin Pencari Buka Halaman
1. Menu Utama Beranda Dashboard — Ringkasan angka utama, grafik trafik, dan aktivitas terbaru noindex, nofollow Buka Beranda
1. Menu Utama Analitik & Grafik — Grafik interaktif kecepatan layanan dan perbandingan wilayah server noindex, nofollow Buka Analitik
1. Menu Utama Pusat Notifikasi & Peringatan — Daftar lengkap pesan keamanan, transaksi, dan siaran pengumuman tim noindex, nofollow Buka Notifikasi
2. Data & Media Data Pengguna — Tabel daftar akun pengguna, pencarian cepat, dan matriks hak akses noindex, nofollow Buka Pengguna
2. Data & Media Detail Pengguna — Halaman profil lengkap pengguna, sesi perangkat, dan riwayat akun noindex, nofollow Buka Detail
2. Data & Media Data Transaksi — Daftar catatan pembayaran, pengembalian dana, dan ekspor CSV noindex, nofollow Buka Transaksi
2. Data & Media Galeri Foto & Video — Unggah file Drag & Drop, susunan gambar Masonry, dan pratinjau penuh noindex, nofollow Buka Galeri
3. Komponen UI Katalog Komponen (UI Kit) — Contoh siap pakai seluruh form, Select2, tabel, rich-text, dan grafik noindex, nofollow Buka Katalog UI
4. Sistem & Keamanan Riwayat Aktivitas (Audit) — Catatan aktivitas pengguna dan perubahan data sistem noindex, nofollow Buka Riwayat
4. Sistem & Keamanan Detail Riwayat Aktivitas — Perbandingan data sebelum dan sesudah perubahan noindex, nofollow Buka Detail
4. Sistem & Keamanan Pengaturan Sistem — Batas waktu sesi, keamanan aplikasi, dan manajemen kunci API noindex, nofollow Buka Pengaturan
4. Sistem & Keamanan Status Server — Pantauan kondisi server dan waktu aktif (uptime) publik index, follow Buka Status
4. Sistem & Keamanan Masuk Akun Admin — Halaman login administrator dan verifikasi kode keamanan (MFA) noindex, nofollow Buka Login
Halaman Bantuan Halaman Error & Offline — Tampilan saat halaman tidak ditemukan (404), akses ditolak (403), atau tanpa internet noindex, nofollow
