Tentang PIUI Zero™

Zero Dependency Admin Dashboard UI Kit & HTML Template

Created by Ipi "Pedro Iriano"

Versi 2.2.2 • Rilis 2026-10-26. Identitas build tersedia dalam data/version.json dan checksum paket.

Cakupan produk

Template HTML/CSS/JavaScript native tanpa dependensi runtime eksternal. Demo menggunakan data sintetis dan perubahan lokal dalam memori halaman. Autentikasi, otorisasi, penyimpanan, audit dan pengiriman pesan memerlukan adapter server.

Brand dan atribusi

PIUI Zero™ — Created by Ipi "Pedro Iriano". Status pendaftaran merek belum diverifikasi. Nama aplikasi akhir pembeli dapat dikonfigurasi terpisah sesuai lisensi; kepemilikan source tidak berpindah.

Lisensi dan distribusi

Paket kandidat ini menyertakan draf ketentuan komersial untuk tinjauan pemilik. Tidak memberikan hak jual ulang template/UI kit, bundling sebagai produk stok atau klaim sebagai pencipta. Pembeli memperoleh hak penggunaan end product sesuai lisensi yang benar-benar diterbitkan penjual.

Dukungan

Tautan resmi, kanal dukungan dan status peninjauan hak aset belum dikonfigurasi. Jangan menganggap domain contoh pada data demo sebagai alamat layanan resmi.
