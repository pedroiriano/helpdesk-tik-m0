2. Formulir Isian, Kotak Pilihan Cari (Select2), & Form Pop-up Kanan

Semua kotak pilihan otomatis memiliki kolom pencarian cepat seperti Select2, dilengkapi 3 variasi Form Pop-up Kanan siap pakai.

Status Form: Siap Diuji
Ukuran huruf nyaman dibaca dan tidak membuat layar HP membesar sendiri.
Klik kotak di atas lalu ketik kata untuk mencari pilihan secara instan.

<div class="piui-field">
  <label for="pilih-jabatan" class="piui-field__label">Pilih Jabatan (Otomatis Select2)</label>
  <select id="pilih-jabatan" class="piui-select">
    <option value="admin">Administrator Utama</option>
    <option value="staff">Staf Operasional</option>
  </select>
</div>

3. Editor Teks Lengkap (Rich-Text / Markdown) & Kotak Kunci API Rahasia

Memudahkan penulisan pengumuman berformat rapi serta menyembunyikan kode rahasia agar aman dari intipan layar.

Lihat & Salin Kode HTML Editor Teks & Kotak Kunci API 
<label for="my-editor" class="piui-field__label">Catatan</label>
<div class="piui-md-editor" data-piui-md-editor>
  <textarea id="my-editor" name="notes" class="piui-textarea">### Judul Pengumuman</textarea>
</div>
Toolbar, mode Tulis / Dua panel / Pratinjau, statistik, dan aksi dokumen dibentuk otomatis oleh markdown-editor.js.
Mode awal opsional: data-editor-mode="write|split|preview". API instance: getMarkdownEditor(host).setMode(mode).
Pintasan: Ctrl/Command+B, Ctrl/Command+I, Ctrl/Command+Enter. Escape dari pratinjau kembali ke naskah.
Untuk konten dinamis: initMarkdownEditors(container). Untuk integrasi: piui:editor-change dan piui:editor-save.

4. Tabel Data Interaktif, Pemilih Rentang Tanggal, & Navigasi Halaman (Pagination)

Pencarian, kalender, sortir, dan paginasi seragam. Tampilan kartu mengikuti ruang yang tersedia; tombol tetap utuh dan mudah ditekan.

6. Navigasi Tab, Papan Tugas (Kanban Drag & Drop), Pohon Hak Akses, & Linimasa

Klik salah satu tab di bawah untuk mencoba papan kerja geser (Kanban), centang hak akses bertingkat, dan linimasa riwayat.

  1. Akun Pengguna Baru Berhasil Dibuat Tahap 1 • Selesai

    Hak akses dasar telah diaktifkan dan diverifikasi oleh administrator.

  2. Pembaruan Pengaturan Keamanan Sistem Tahap 2 • Aktif

    Perlindungan keamanan halaman dan pembatasan ukuran unggah file telah diterapkan.

Kontrak API dan beberapa instance

Sumber kanonis: editor/table/popup. Inisialisasi berulang tidak menggandakan listener. Contoh di bawah terisolasi; filter tabel kedua/ketiga memakai namespace URL sendiri.

Grup aksi responsif

Konten memakai stack berjarak; tombol memakai grup aksi yang membungkus ke baris baru ketika ruang menyempit.

Buka Dashboard Portal
API dan state komponen

Editor: createMarkdownEditor, getValue/setValue/setMode; piui:editor-change dan piui:editor-save cancelable. Tabel: initDataTables(root), data-table-scope, data-table-for. Popup: bindPopup, show/close/isOpen. Form: data-adapter, piui:form-submit. Kanban: initKanbanBoards(root), data-kanban dan data-add-kanban. State: loading/populated/empty/error/stale melalui createDataState.

Keyboard: Tab, Enter/Space, Escape, Ctrl/⌘+K. Editor: B/I, Z/Y, Ctrl+Enter. Browser harus mendukung dialog/popover native, CSS layers/container queries dan ES modules. Dokumentasi pembeli pada paket menjelaskan fallback dan batas integrasi.
