# ADR 0005 — M0-04 tiket, durable audit dan lampiran privat

5 November 2026. Scope lokal sintetis; bukan aktivasi produksi. M3 tetap writer tiket tunggal. Tidak mengaktifkan M0-05/M0-06.

Create memakai snapshot atomic milik M2 melalui port, baseline classifier deterministik M4 dan kalkulator kalender CAL-1 M6 (Senin–Jumat 08–16 WIB, versi lab dengan target delapan jam kerja). Proposal/target disimpan sebagai snapshot; belum final classification/dispatch, holiday master resmi atau scheduler. Dependency ini bukan stub sukses. Policy/form immutable dibaca bersama versi layanan. Expected service/form/policy versions wajib; perubahan layanan memerlukan review pemohon. Snapshot konsisten M2 diambil pada satu transaksi read-only repeatable-read; tidak ada lock lintas owner.

Guest membawa capability acak 32 byte hex yang dibuat Web Crypto sebelum create, hanya hash/scope/expiry/revoke di DB. Create idempotency diikat hash capability; raw secret tidak masuk receipt. Tracking memakai HMAC berlabel atas capability dan session_key untuk cookie singkat dengan hash DB. Pengguna menyimpan kunci melalui tindakan salin eksplisit dari field password, bukan URL/storage/draft. Hilangnya kunci tidak dipulihkan lewat nomor tiket. M1 principal dan tracking berbeda; sesi M1 yang tersedia menjadi authority dan tidak digantikan cookie tracking lama. Logout tracking mencabut sesi, revocation capability membatalkan seluruh sesi terkait.

Outbox metadata merupakan primitive infrastruktur per owner, bukan repository bisnis bersama. Setiap module factory menyediakan source yang terikat schema/pool sendiri. Composition root merelay DTO ke M9 consumer; tidak menambah edge bisnis sinkron M3→M9. Lease dan retry disimpan di DB dengan token lease, ACK cocok lease, inbox+efek atomik di M9. Target fase mendatang tetap PENDING, tidak dihapus/ACK palsu. M9 menerima AuditRecorded dan snapshot TicketCreated/TicketStateChanged; projection monoton dan audit immutable. M1/M2 backlog audit ikut diproses. Tidak mengirim kanal nyata atau NotificationStored palsu.

Lampiran M3 disimpan privat pada volume Docker terpisah, kunci UUID server, mode file 0600; filename tidak digunakan untuk path. Quarantine/PENDING metadata, streaming bounded, MIME/signature/decode gambar, checksum, quota per tiket dan ClamAV INSTREAM nyata. Scanner tidak tersedia/timeout mempertahankan quarantine; retry scan terkontrol pada owner dan startup worker. Hanya CLEAN boleh didownload setelah pemeriksaan live ACL; storage key tidak pernah dikirim ke browser. Visibility REQUESTER/INTERNAL merupakan scope tambahan terpisah dari visibility PRIVATE historis. Blob ditulis sebelum transaksi metadata; reconciliation memakai grace period dan referensi metadata, tidak purge data kerja. Pending/blob hilang menjadi status gagal yang jujur.

ClamAV image resmi 1.4.6 dipin digest sha256:8ad6197396974726c35d017e50aaaaf4b91745726a04faec8480c203edd98052. Database signatures bawaan diverifikasi runtime; hasil QA mencatat versi/signature. Jaringan scanner internal, tanpa port host; budget terpisah dari Go M0, dicatat untuk fairness. Freshclam/signature age adalah gate operasi lab/produksi, bukan klaim antivirus lengkap. Referensi: https://docs.clamav.net/manual/Installing/Docker.html dan https://docs.clamav.net/manual/Usage/ClamdProtocol.html. Minimal scanner/storage dibawa maju dari penundaan technology lock karena keamanan lampiran dasar sudah diwajibkan M0-04.

Migrasi 013 M3, 014 M1, 015 M2 dan 016 M9 dan 017 M3 scan queue additive, historical 001–012 immutable. Readiness wajib domain versi 4 M3/M9. Mutation/history/idempotency/audit/outbox atomik per owner. State awal OPEN/PENDING; komentar/lampiran menaikkan versi tanpa transisi lifecycle. Tidak ada permission admin konfigurasi untuk membaca tiket. Peran scope assigned tetap membutuhkan assignee aktual; belum ada assignment melalui UI pada fase ini.

Patch scanner dipilih setelah memeriksa rilis keamanan resmi Agustus 2026: https://blog.clamav.net/2026/08/ . Kandidat awal 1.4.3 diganti sebelum penerapan aplikasi M0-04; bukti final hanya berlaku untuk versi terpin akhir.
