# Pengarah Antigravity Gemini

Baca dan ikuti AGENTS.md di root workspace ini sebagai aturan proyek canonical. Lalu baca README.md dan status/PROJECT_STATE.md untuk task aktif. Rincian berada di docs/01_BLUEPRINT_M0.md, docs/02_ATURAN_PEMBANGUNAN.md dan docs/03_PANDUAN_AGENT_AI.md. Jangan membuat aturan bisnis paralel khusus Gemini.

Buka folder Helpdesk-TIK-Depok-Monolith-Modular sebagai workspace root. Pada sesi baru, sebutkan file aturan yang benar-benar dibaca serta batas M0 satu proses. Jika aturan belum termuat otomatis, buka file tersebut secara eksplisit sebelum coding. Jangan menganggap artifact plan atau walkthrough sebagai bukti tes.

Gunakan planning/backlog.csv dan status/evidence.jsonl yang sama dengan Codex. Prompt portabel tersedia di prompts. Pergantian agent menggunakan templates/HANDOFF.md. Tidak perlu mengubah konfigurasi global atau mengaktifkan eksekusi tanpa batas untuk menggunakan paket ini.
